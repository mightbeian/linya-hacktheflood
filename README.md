# 🇵🇭 LiNYA - Linis na Yaman ng Bayan

> *"Sama-sama sa Tamang Linya"* (Together on the Honest Line)

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)
[![Made with React](https://img.shields.io/badge/Made%20with-React-61DAFB?logo=react)](https://reactjs.org/)
[![PWA Ready](https://img.shields.io/badge/PWA-Ready-5A0FC8?logo=pwa)](https://web.dev/progressive-web-apps/)

**LiNYA** creates mutual accountability in Philippine society by empowering the homeless with resources and security while preventing corruption from both officials and citizens.

## 🎯 Mission

To build a Philippines where honesty is normal, the vulnerable have power and protection, and services reach those who need them.

## 📱 Core Modules

- **SafeSpace PH** - Offline-first resource mapping for homeless services
- **StreetConnect** - Secure digital identity and document management  
- **Anti-Corruption** - Anonymous reporting with encrypted evidence
- **Citizen Accountability** - Two-way integrity scoring system
- **OddJobs** - Same-day employment platform
- **Transparency Dashboard** - Public budget and performance tracking

## 🚀 Quick Start

```bash
git clone https://github.com/mightbeian/linya-hacktheflood.git
cd linya-hacktheflood
npm install
npm run dev
```
